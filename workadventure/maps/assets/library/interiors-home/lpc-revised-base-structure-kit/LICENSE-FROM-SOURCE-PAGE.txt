Description from the page (excerpt):
A collection of about 100 LPC structural elements files, each item colored to fit the Liberated Palette.

Many elements are pre-existing base LPC, revisited, expanded, and given extra color options. New items include a plain fence, new floor and wall options, an expanded roof, a stovetop element for the cast icon stove, and animated arched castle doors.

All up to date assets for the LPC Revised project can be found on my Github page here: https://github.com/ElizaWy/LPC
