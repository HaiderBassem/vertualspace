# Nature set and garden

AdminSpace's built-in catalog (`catalog/builtin`, generated by `npm run catalog:generate` from `scripts/catalog/`) has a
**Nature** category, places to sit outdoors and a garden room. Everything is original artwork drawn in code
(`scripts/catalog/nature.ts`, `garden.ts`).

| Group         | Components                                                                                                                            |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Places to sit | Beanbag, Garden bench (4 directions), Tree stump stool, Log bench, Rattan chair (4 directions), Hammock. Category _Seating_.          |
| Trees, hedges | Oak tree (summer, autumn, blossom), Pine tree (plain, snow), Bush, Hedge.                                                             |
| Flowers       | Flower bed (tulips, daisies, lavender), Raised planter (herbs, vegetables), Potted palm, Fern, Bamboo.                                |
| Water, stone  | Pond (lilies, koi), Fountain, Rock cluster, Stepping stones, Grass patch (meadow, clover, wildflowers), Picnic table, Garden lantern. |
| Room template | **Garden terrace** (22 x 14): fountain at the end of the path, pond, trees, picnic table, benches, hammock, beanbag circle.           |

Walking and collisions follow the other components: trunks, basins and hedges block, canopies are walked behind, ground
pieces (stepping stones, grass) sit under the players. All places to sit can be sat on and claim nothing by themselves
(see [DESKS.md](DESKS.md) for desks).

The garden template places two native video-meeting areas (LiveKit): at the picnic table and among the beanbags.

## Getting the components into a world

Importing the catalog (done at every start of the image) publishes the components to every organization. A world uses a
component once it is installed in it (Components page, or in bulk):

```sh
docker compose exec adminspace node build/cli/catalog-install.js --org acme --world office --category nature
docker compose exec adminspace node build/cli/catalog-install.js --all            # every world, every platform component
```

The command is idempotent; the installed components appear in WorkAdventure's map editor after the rooms are linked
(a background job, a few seconds).

## Adding more

Add a drawing function and an entry to `NATURE_ENTITIES` (names and descriptions in the five languages), run
`npm run catalog:generate`, then `npm run catalog:import`. Keep image sizes multiples of 32 px (collision grids are
32 px cells, rows x columns of the image), and at most 16 variants per component.
